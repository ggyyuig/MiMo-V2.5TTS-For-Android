声音复刻 / 自定义音色
VoiceClone

上传或录制一段你有授权的声音样本，保存后会加入“生成语音”的音色列表。建议样本 10–30 秒、环境安静、单人声音；最稳是 mp3/wav。

上传 m4a/webm 时接口可能不接受；本 APP 录音会保存成 wav。
