# MiMo V2.5 TTS For Android

这是一个基于 **MiMo V2.5 TTS** 的安卓端语音合成项目仓库，主要用于在移动端调用 MiMo TTS 接口，将用户输入的文本转换为语音音频。

项目目标是做一个可以在安卓手机上使用的语音合成应用，让用户能够通过简单的界面完成文本输入、接口配置、音色设置、语音生成、音频预览和后续保存等操作。

本仓库目前同时保留了两个版本，方便进行版本对比、功能回退和后续继续维护。

## 项目结构

```text
MiMo-V2.5TTS-For-Android/
├─ MiMoTTS-MobileAppV1.0/   # 旧版本项目
├─ MiMoTTS-MobileAppV2.0/   # 新版本项目
└─ README.md                # 仓库说明文件
```

## 功能介绍

当前项目主要包含以下功能方向。

### 1. 文本输入

用户可以在应用中输入需要转换为语音的文本内容。

文本输入区域主要用于填写 TTS 合成内容，可以支持短句、段落或较长文本。后续可以继续扩展字数统计、输入限制、清空文本、一键粘贴等功能。

### 2. 文本转语音

应用通过调用 MiMo TTS 相关接口，将输入文本发送到后端或接口服务，并接收返回的音频结果。

该功能是项目的核心功能，主要流程为：

```text
输入文本 → 配置接口参数 → 发起请求 → 接收音频结果 → 播放或保存
```

### 3. API 设置

应用提供 API 配置入口，用于填写和管理接口调用所需的信息。

常见配置项包括：

- API Key
- API URL / Base URL
- 模型名称
- 请求格式
- 认证方式
- 其他接口参数

为了安全，不建议将真实 API Key 写死在代码中，也不建议直接提交到公开仓库。更推荐通过应用设置页面在本地填写。

### 4. 音色配置

项目计划支持音色相关设置，让用户可以根据需要选择不同的声音风格。

可扩展的音色参数包括：

- 音色名称
- 说话人 ID
- 语速
- 语调
- 音量
- 情绪风格
- 描绘音色文本

具体参数需要根据 MiMo TTS 接口实际支持情况进行调整。

### 5. 语音预览

语音生成完成后，用户可以在应用中直接播放生成的音频，确认效果是否符合预期。

后续可以继续扩展：

- 播放 / 暂停
- 重新生成
- 保存音频
- 分享音频
- 历史记录
- 音频文件管理

### 6. 移动端界面适配

项目以安卓手机端使用为主要目标，界面布局需要适配竖屏手机。

界面设计方向：

- 功能入口清晰
- 操作流程简单
- 适合触屏点击
- 设置项集中管理
- 页面不拥挤
- 保持接近成品 App 的观感

## 使用方式

### 使用 Android Studio 打开项目

1. 下载或克隆本仓库
2. 打开 Android Studio
3. 选择 `Open`
4. 进入 `MiMoTTS-MobileAppV2.0` 文件夹
5. 等待 Gradle 自动同步
6. 检查 Android SDK 和 Gradle 配置
7. 连接安卓手机或打开模拟器
8. 点击运行按钮进行调试
9. 构建 APK 后安装到手机使用

### 推荐打开的目录

当前建议优先打开：

```text
MiMoTTS-MobileAppV2.0/
```

不要直接只打开仓库根目录，否则 Android Studio 可能无法正确识别实际项目结构。  
如果根目录无法识别 Gradle 项目，请进入 V2.0 文件夹后再打开。

## API 设置说明

应用中需要配置 MiMo TTS 相关接口信息，一般包括：

- API Key
- API URL / Base URL
- 模型名称
- 音色参数
- 输入文本内容

请根据 MiMo 开放平台提供的真实接口文档填写参数。

示例配置项：

```text
API Key: 自己的接口密钥
Base URL: 接口基础地址
Model: MiMo V2.5 TTS
Voice: 选择或填写音色参数
Text: 需要合成的文本
```

注意事项：

- 不要把自己的 API Key 直接提交到公开仓库
- 不要把真实密钥写死在代码中
- 如果接口请求失败，需要检查 API Key、URL、网络环境和请求格式
- 如果没有返回音频，需要检查接口返回内容和错误信息
- 如果音频无法播放，需要检查返回格式是否为手机可播放的音频格式

## 编译与运行说明

如果使用 Android Studio 构建，请注意以下内容：

- 确认已安装 Android Studio
- 确认 Android SDK 已正确配置
- 确认 Gradle 能正常同步
- 确认项目路径中没有特殊符号
- 确认网络环境可以下载依赖
- 如果依赖下载失败，可以尝试更换网络或重新同步 Gradle

常见操作：

```text
Open Project → Gradle Sync → Run App → Build APK
```

如果需要生成 APK，可以在 Android Studio 中选择：

```text
Build → Build Bundle(s) / APK(s) → Build APK(s)
```

生成后可以在 Android Studio 的提示中点击 `locate` 找到 APK 文件。

## 常见问题

### 1. Android Studio 打不开项目

可以检查以下内容：

- 是否打开了正确的项目目录
- 是否存在 `settings.gradle`
- 是否存在 `build.gradle`
- Gradle 是否同步成功
- Android SDK 是否安装完整

如果仓库根目录无法打开，可以尝试直接打开：

```text
MiMoTTS-MobileAppV2.0/
```

### 2. 项目无法编译

可能原因包括：

- Gradle 版本不匹配
- Android Gradle Plugin 版本不匹配
- SDK 版本缺失
- 依赖下载失败
- 网络环境无法访问依赖源
- 项目文件移动后路径变化

可以先尝试重新同步 Gradle，或者根据 Android Studio 的报错信息逐项修复。

### 3. API 调用失败

可能原因包括：

- API Key 错误
- API URL 填写错误
- 请求参数格式不正确
- 网络连接失败
- 接口服务不可用
- 模型名称填写错误
- 账号额度不足或权限不足

建议先查看接口返回的错误信息，再根据错误码进行处理。

### 4. 生成的音频无法播放

可能原因包括：

- 返回内容不是音频文件
- 返回的是错误 JSON
- 音频格式不被当前播放器支持
- 文件保存路径错误
- 缺少存储权限
- WebView 或播放器没有正确加载音频地址

可以先确认接口返回结果，再判断是合成失败还是播放失败。
